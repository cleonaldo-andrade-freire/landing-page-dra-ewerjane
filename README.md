## 🔧 Personalizações Obrigatórias

Antes de publicar, preencha os campos marcados com `[...]` no `index.html`:

1. **Endereço completo** — Busque por `[ENDEREÇO COMPLETO]` e `[CEP]`
2. **Link do mapa** — Substitua o `src` do `<iframe>` pelo link embed real do Google Maps do endereço da clínica
   - Acesse: Google Maps → pesquise o endereço → Compartilhar → Incorporar mapa → copie o `src`
3. **Links do GPS** — Atualize os links do Google Maps e Waze com o endereço real:
   - Busque por `maps.google.com/?q=Aracaju,SE` e substitua pelo endereço real URL-encodado
   - Busque por `waze.com/ul?q=Aracaju,SE` e substitua pelo endereço real

## 🚀 Como publicar

**Opção 1 — GitHub Pages (gratuito):**
1. Crie um repositório no GitHub
2. Faça upload dos arquivos
3. Ative GitHub Pages nas configurações

**Opção 2 — Netlify (gratuito e mais rápido):**
1. Acesse netlify.com
2. Arraste a pasta `DraEwerjane` para o painel
3. Pronto! Site no ar em segundos

**Opção 3 — Hostinger / HostGator (hospedagem paga):**
1. Faça upload via File Manager ou FTP
2. Aponte o domínio para a pasta
